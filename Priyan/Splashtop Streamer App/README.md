# Splashtop Streamer

This folder contains the Splashtop Streamer documentation in Markdown format.

## Files

- `Splashtop.md` — visually exact rendering of the supplied Word document.
- `images/` — page images used by `Splashtop.md`.

## GitHub Structure

```text
Splashtop/
├── README.md
├── Splashtop.md
└── images/
    ├── page-01.png
    ├── page-02.png
    ├── ...
    └── page-12.png
```

The Markdown uses relative image paths, so GitHub will display the pages directly when the folder is uploaded to a repository.
